# 正式前端接入 Demo

采用最新 Demo 的照片背景、暖纸浅色、薄荷强调、固定导航、精选文章、分屏登录、学习卡和月度账本。前端无新增框架或外部字体依赖。

## 数据与功能

首页、文章、归档保留服务端 HTML；首页统计及账号状态使用真实数据，搜索复用 `/search`，无脚本也可提交搜索和浏览文章。归档分类、年份和标签通过渐进增强筛选。文章保留 Markdown、MathJax、封面、目录与代码复制，并按访问权限生成相邻文章。

登录注册使用现有 POST 路由，保留邀请码、关闭注册和错误回显。日历与待办继续局部刷新和校验 CSRF。单词继续真实词库、评分、账号进度和原间隔规则。账本继续所有服务端校验与分页，不用 Demo 的内存示例数据。手机工具页采用紧凑封面、表单优先和悬浮记账入口。

## 验证

- `python -W ignore::ResourceWarning -m unittest discover -s tests`。
- 浏览器在隔离数据库验证：访客/管理员私密可见性、文章搜索、归档、登录、待办新增/编辑/勾选/刷新持久化、记账新增/修改/CSV、单词评分写入/词库搜索、主题持久化和手机菜单。
- Edge / Playwright：7 类页面 × 320 / 390 / 768 / 1024 / 1440 × 深浅两主题，共 70 组无横向溢出、无脚本错误及资源加载失败。
- `demo/` 的现有修改保持原样，仅作为本次适配来源；Sunny 独立服务不变。

## 部署与回退

生产部署只同步列明的代码、模板和 UI 资源。上线前保存旧文件及 SQLite 一致性备份；Nginx 无需修改。服务重启会清空既有内存会话，用户需重新登录一次。回退时恢复备份代码文件并重启 `timelessice`，数据库不需要回滚。
